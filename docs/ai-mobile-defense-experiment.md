# 从高手对局思路到可验证的运营应对

2026-10-26。[实际录像研究](ai-top-player-playbooks.md)、[13组独立开发试验](ai-top-player-pilots/report.md)。狗的机动性是保留的问题，但护卫、减兵和全部额外步兵静态留家的方案没有证明优于C18；这些失败方案不直接发布。

研究强调机动压制必须同时保住收入。原始实战报告显示苏军长期缺少履带，飞行兵持续击杀矿车，因此本项按测评计划P2a单独验证可见空袭后的生产应对。只改brutal四个苏军国家，真实前提可生产时优先HTK，每辆正常花费；目标数量2–6、短时记忆600tick，不改视野、伤害、资源或普通难度，不让防空策略冒充狗协同收益。

## 判定和归因

三组分别核验所有job、两个raw artifact和汇总artifact，原始字节哈希、唯一对局、换边、规则/地图/地形及错误数。错误和缺局不算平，真正超时按平局。候选W>L仅为开发正线索；完整平衡C18自测W=L只通过一致性检查，`screeningPositive=false`、`qualified=false`，不能包装成新策略获胜。完整有效但W≤L时报告为战力筛选失败；运行失败另取具体日志。

报告按国家、地图和出生侧拆分，并保留首坦克/履带、真实产量、履带对空武器射击、坦克伤害与战损、飞行兵对矿车的`damagedTypes`和`killedTypes`。对比实际经济结果，不假称整局花费相同。30tick移动采样区分任务狗与侦察狗，静止不等于等待狗；900tick任务快照无记录不等于从未分配。

此前356苏军对C18美国的8胜，与C18自身对美国的2胜6负，是同条件公共对手比较，不能写成两组直接交战；这两个8局不是国家平衡完整自测。旧样本及本轮新样本分开，所有原型的败局/平局保留。

独立资格仍需三图、注册的三套未见种子和按地图/种子分块的区间，以及消融/独立战术对手、普通难度回归、历史三基线各432局80%总/70%每国每图/零错检查。开发筛选不能授权发布；master保留C18 AI与他人后续部署/资源/地形改动，不覆盖、不force-push。完成本轮后按具体结果继续实现与验证，不停在一份失败报告上等用户再次催促。
