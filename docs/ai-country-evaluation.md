## 本轮实现与验证范围

- 已加入伊拉克辐射兵、英国狙击手、德国坦克杀手、苏俄磁能坦克的条件支援，按实际科技、可见敌军和全军数量上限选择；法国巨炮包含受压防守开局，美国调用真实已充能伞兵能力。后期幻影/天启补充主力，攻城保留坦克与防空护卫。
- 辐射兵默认使用束射，部署前检查友军、生产出口与前进通道；收起后仍避开已观察的残留污染。V3不把发射器Damage=1当导弹伤害，不追移动部队；伤坦利用真实武器冷却后撤，保护首发蓄力、连发与部署动画。
- 分兵只使用已有富余健康坦克，可从多支已出击队汇集，保留每支主队及全军核心，不追加骚扰生产需求。基地遇袭、目标失去可见性或局部劣势时返回，回程不反复重启同一路径。
- 第一重工原两格间距无合法落点时，Brutal尝试一格间距，并检查真实出厂通道、地形、占用和引擎合法性。普通难度保持原政策。

机制验证使用真实GameFactory/Game.update。八个特色场景及分兵场景已通过；伞兵场景预置了充能，其他场景预置军队，因此它们不证明经济运营或完整对战胜率。此前伤坦场景确实失败，修正PrepareToFire包含冷却等待的判断后通过；失败记录与修正后记录均见[实验索引](ai-national-experiments.json)。辐射残留场景实际表现为坦克等待污染消退后通行，不应称为已经证明其会绕行。

第一版28局开发赛程为11胜8负9平；第二版对第一版同国直接对照4胜0负。两版对旧版的开发赛程构成不同，不能直接拿总胜率作升级幅度。本页432局使用同一个最终快照。全套测试244通过、13条件跳过、0失败；entry/server/benchmark/特色场景/分兵场景类型检查及生产构建通过。未运行真实PvPGN联机或真人对抗。

韩国专用黑鹰空袭、古巴/利比亚运输爆破和美国主动敌后空降选点尚无专门控制器；当前伞兵优先增援安全可见集结点。国家特色与后期能力是否在本赛程实际触发，须以下述遥测为准，不能由国家配对表推定已有效利用全部特色。

候选DESO实际展开 **0** 次；独立骚扰队实际启动 **6** 次；候选伞兵能力实际激活 **16** 次。辐射持续伤害按受害方记录为候选 0 HP、对手 0 HP；引擎污染区不带归属，不能把所有环境伤害虚构为候选DESO战果。

零触发项表示本批完整对局没有使用证据，即便机制场景或单元测试已通过；它们应作为下一轮改进目标。开火/产出数量也不等于独立带来了胜局。


遥测口径：`damageDealt` 沿用旧计数，含过量伤害和中立对象；`specialty.damageBySourceType` 按实际掉血估算，不等于单独带来胜局。产出计数使用真实出厂/落地事件，队列完成不等于已经建成。末态资产按存活对象规则造价相加，不计现金与残血折价。900 tick采样不能独自证明短时操作因果；独立骚扰启动另由精确日志计数。伞兵能力是正常规则的已充能能力，正式赛程没有预充能、预置军队或额外资源。


## 退步后的再迭代

第二版扩大到284局时为103胜141负40平，零捕获运行错误；因此主动停止，没有把它写成完整432局成绩。隔离实验中，扩大防守征召范围没有收益，只让车辆后撤也未改善；换回旧战斗控制则减轻退步，进一步定位到目标评分。恢复可展开武器的规划估值、去掉仅凭名义射程排除其他目标的硬筛选后，两图直接对第二版为4胜2负2平，其中中图2胜0负2平。实际命令仍按当前姿态和引擎合法性执行，V3仍限固定建筑目标。

最终第三版重新使用10111/20222/30333三个种子与独立输出目录，未混入第二版的局数。上述实验提交与逐局记录见[实验索引](ai-national-experiments.json)；它们是诊断过程，不是额外的最终样本，也不能只挑胜局计算胜率。
