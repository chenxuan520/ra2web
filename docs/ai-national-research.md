## 本项目已经核对的机制

以下数值来自本地 `public/ini.mix` 与 `public/res/ra2cd.mix` 合并规则，作为本次检查记录；实战仍读取地图覆盖后的运行时规则。

| 对象 | 本地规则记录 | 实现含义 |
| --- | --- | --- |
| 伊拉克辐射兵 `DESO` | 国家键 `Arabs`，造价600，生命150，手持武器射程6；部署武器 `RadLevel=500`、`Range=4`。 | 辐射兵不可碾压、有自疗、免疫辐射。国家显示名不能直接当规则键。 |
| 部署污染 | `RadEruptionWarhead.CellSpread=10`；引擎创建污染区时用 `cellSpread + 1`，即半径11。 | **不能拿部署武器的射程4或手持射程6当友军安全范围。**长期伤害与距离衰减另行计算。 |
| 法国巨炮 `GTGCAN` | 国家键 `French`，造价2000，生命900，耗电100；射程15、最小射程3，弹头范围2。 | 真正ID是 `GTGCAN`，没有 `GTGC`。炮台有近身死角且需要供电。 |
| 光棱 `SREF` | 生命150、轻甲、造价1200、速度4；主武器射程10。 | 在默认规则下不能隔着安全距离拆射程15的巨炮；脆弱，需护卫。 |
| V3 | 生命150、轻甲、造价800、速度4；发射器射程18、最小射程5。 | 发射器是 `Spawner`；其 `Damage=1` 不是生成导弹的实际伤害，普通伤害评分需专门处理。 |

- [MapRadiationTrait.ts](../ts-redalert2/src/game/trait/MapRadiationTrait.ts) 的持续辐射对地面单位逐个结算，没有敌我阵营过滤；[Warhead.ts](../ts-redalert2/src/game/Warhead.ts) 排除辐射免疫单位和非单位对象。**普通友军会受污染伤害，建筑不能靠这类辐射拆除。**不能只把DESO编进犀牛队，再在队伍正中无条件展开。
- [DeployerTrait.ts](../ts-redalert2/src/game/gameobject/trait/DeployerTrait.ts) 根据现存辐射水平和规则计算部署武器的续放冷却；收起不等于抹除已经存在的污染。[MapRadiationTrait.ts](../ts-redalert2/src/game/trait/MapRadiationTrait.ts) 另行衰减污染。因此“打一发就连续收展”和“友军马上穿过刚收起的位置”都要实测，不能假定安全或更高输出。
- [RulesApi.ts](../ts-redalert2/src/game/api/RulesApi.ts) 暴露实际辐射规则；武器射程、最小射程、弹头装甲倍率、可攻击空地类型也应来自实际规则。地图可以覆盖规则，不能把攻略的射程表作为最终判断。
- [MapApi.ts](../ts-redalert2/src/game/api/MapApi.ts) 提供当前可见性和通行查询。部署位置、坦克后撤点、炮兵站位必须同时满足可见信息、通行和命令限制；不能通过研究资料引入对全图隐藏敌军的读取。

## 伊拉克：辐射兵承担区域拒止，坦克负责突破

建议用可见敌军构成驱动辐射兵需求：敌方有步兵团、靠近的轻装甲或密集阵地时，少量辐射兵补足犀牛的反步兵和区域控制；主要目标是建筑、空军或免疫单位时，继续维持主战坦克、拆楼火力和防空。雷达投资也必须与采矿及最低防守部队相容。

部署前检查敌方有效目标、污染半径内易受伤友军，以及坦克/步兵正在通过的通道。没有有效地面敌军时不要展开；友军将穿越时优先换位或维持手持武器。敌人离开、友军逼近或编队要转移时，按状态和最小驻留时间决定收起，避免每个更新周期反复切换。反复收展后的既有污染仍需单独规避。

辐射突袭是另一种战术：防空履带运载、选择安全卸载点、下车展开和后续撤离都需要独立状态机。应另设对照实验，不能在没有运输控制的情况下宣称“辐射炸弹”已经完成。

## 法国：把巨炮作为有电力和近卫支撑的防区

巨炮建设应有明确价值：可见地面威胁、需要长期保住的矿区/生产设施，或当前合法邻接范围内能覆盖的争夺点。放置评分考虑有效射程覆盖、最小射程死角、友军近卫距离、维修与电力设施位置，优先覆盖此前没有覆盖的方向。不要为了“使用国家特色”就消耗前期全部坦克预算。

电力不足时先恢复电力；空军威胁需要IFV或其他防空，贴身敌军需要坦克/步兵近卫。新增巨炮必须提高有效覆盖，并且经济能承担建造及保护费用。对手如果转去袭击外部矿车，机动军队仍需响应，不能把所有资金锁在基地内。

应同时测试AI使用和对抗巨炮：坦克避免沿同一路线逐辆进入炮区；可攻击外围经济、破坏电力，或使用实际射程足够且不会被防空拦截耗尽的攻城武器。射程更短的光棱不能因被标记为“炮兵”就误认为可以无伤拆巨炮。

## 长期战组合与国家专长

以下是职责设计，具体是否投产由当前可用性、可见敌情和经济决定，不是固定生产清单。

| 部队/国家 | 候选职责 | 必须补足的短板 |
| --- | --- | --- |
| 灰熊/犀牛 | 机动主体，保护矿区，屏护支援单位；形成足够同时开火的正面。 | 不为追单个远处目标破坏整队；避免把少量坦克逐辆送进成型阵地。 |
| 幻影 + 灰熊 + IFV | 幻影反地面单位、灰熊维持机动和护卫、IFV按空袭需求补充。 | 幻影有可输出目标时尽量停稳；不能假定伪装允许无视敌人已经合法发现的位置。 |
| 光棱 + 主战坦克 + IFV | 逐步清除固定防御与步兵团，坦克阻挡突进。 | 炮兵不上前扛伤；比较每个目标实际射程；对移动装甲不保证优于主战坦克。 |
| 犀牛 + DESO + 防空履带 | 坦克突破、辐射兵控地面接近方向、防空保护。 | 分开污染区与普通友军的站位/移动走廊；对建筑维持有效火力。 |
| 犀牛 + 少量V3 | 对缺少拦截能力的固定目标远程施压。 | 不追移动坦克；护卫跟上；导弹连续被拦截时不应无限增产V3。 |
| 天启 + 快速护卫 | 经济成熟时提供重装推进和据点战能力。 | 慢速导致脱队，不能让快坦克先冲、天启很久才到；不要只因“后期”就全部改产天启。 |
| 德国坦克杀手 | 对可见装甲比例高的敌军追加专门反坦克火力。 | 对步兵、建筑效率差，必须保留通用和反步兵单位；按真实弹头倍率选敌。 |
| 英国狙击手 | 后排清理高价值步兵，包括可见的辐射兵。 | 避开坦克突进；没有步兵目标时限制投入；若要进IFV，需要单独运输/武器变换管理。 |
| 苏俄磁能坦克 | 按本地武器倍率提供特定地面火力补充。 | 不能照搬旧文的固定1:3比例；其射程、装甲和成本与犀牛直接比较。 |
| 恐怖机器人 | 选择缺少反制、可成功接近的车辆目标，牵制/骚扰。 | 入侵规则和正在被占用目标需专门处理；不能按普通炮弹伤害评分，也不能承诺拆建筑。 |
| 韩国黑鹰、美国伞兵 | 有机场/能力时形成可重复支援或压力。 | 空袭需弹药、返航、机场与防空路径管理；空降需合法落点和落地后的单位接管。 |
| 古巴恐怖分子、利比亚自爆卡车 | 有运输/接近路线和高收益目标时的专门突袭。 | 自爆误伤和路途中被引爆的风险高，应从普通主力编队中分离；不能只加生产权重。 |

“长期战”至少分为保收入、补缺失兵种、形成受保护的拆楼能力、持续压制四个问题。先判断新增科技/重工的投资是否延误采矿和防守，再让昂贵支援逐步进入现有主力；不能用持续时间一个条件取代经济和战场判断。

## 坦克微操的可测设计

1. **按伤害分配火力。** 使用目标装甲、剩余生命、武器当前可用性与已分配的齐射伤害，减少全队追打一个残血目标。优先可就地输出的敌军，再考虑追击距离；不能把派出的命令当成已经命中的伤害。
2. **开火优先于移动刷新。** 准备开火、开火动画和连发过程中不反复刷新移动命令。只有冷却窗口、实际射程/速度优势和安全可达落点同时满足时才尝试拉扯；慢速天启不套用灰熊的撤退节奏。
3. **前排轮换和后排站位。** 受集火且撤得出的单位短撤，其余单位继续射击；光棱/V3保持主力后方，防空单位避免变成最前排肉盾。不要用后撤命令把整队不断拉离攻击范围。
4. **按地形展开。** 宽阔地减少前后多排遮挡，窄口先集结并保持拆防御火力；分侧接敌需要同时到达和独立路径，不能为了侧翼形状把主力拆散逐个送掉。
5. **处理特殊目标。** DESO、巨炮、幻影、恐怖机器人各自有免疫、最小射程、伪装或入侵条件。先验证能否攻击与命令是否有效，再计算普通威胁分数。

## 验证安排

- 机制场景先验证：辐射确实触发、有敌军损失、友军污染受控；巨炮在合法位置建成、有电能开火，并在最小射程/空袭场景中得到近卫响应；坦克变更检查开火次数、实际战损、单位脱队及重复命令。
- 完整对局使用冻结旧版和上一稳定版，至少包含伊拉克对法国、法国对伊拉克、国家镜像和原有美苏回归。固定资源/加成，交换出生点与更新顺序；让一部分地图更适合经济发展，另一些检验快攻压力。
- 长局和短局分别报告。长期战场景需确认实际建出了目标科技/特色单位，否则“这局赢了”不能证明特色兵种或后期配合有效。
- 记录各单位产出时间与数量、特色武器开火/部署、造成与承受的有效伤害、友军污染、矿车及电力状态。污染的持续伤害若没有攻击者归属，应作为环境伤害单独记录，不虚构为某个DESO的击杀。
- 比较胜/负/平和机制指标，保留退步场景；限时为平、运行错误为无效。独立种子与未参与调试的地图用于验证，单个剧情式战斗不能替代完整对局，也不能证明人类无法获胜。
